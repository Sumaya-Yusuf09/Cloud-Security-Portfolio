# Cloud-Security-Portfolio

This is where I put cloud security projects as I build them, mostly in Azure.

I studied IT and Business and moved into cybersecurity after that. I have the AZ-900 and SC-900 certifications. This repo is just the practical side of that, actually building things instead of only reading about them.

Each project has its own folder with a README and screenshots showing what I did and why I did it that way.

Right now the portfolio is a work in progress. I'm adding projects one at a time as I build them, so this main page will grow along with it. If you're a hiring manager or just someone interested reading this, feel free to go into any project folder for the full breakdown, and reach out if you want to talk through any of it.
