# Cloud Security Portfolio

Hi, I'm Sumaya. This is where I build and document real, hands on Azure security work. Every project here started from a real business problem, something a company would actually run into, and I worked through it the same way someone on a security team would, including the mistakes and the troubleshooting along the way.

## Projects

**[Project A: Identity and Access Management in Microsoft Entra ID](<Project%20A%3A%20Identity%20Access%20Management>)**
Built out Conditional Access policies requiring MFA and blocking sign in from outside the EU, tested them with the What If tool, set up time limited admin access through Privileged Identity Management, and ran through a full employee offboarding from group removal to account disable.

**[Project B: Storage Misconfiguration and Hardening](<Project%20B%3A%20Storage%20Misconfiguration%20and%20Hardening>)**
Deliberately exposed an Azure Blob Storage container the same way real companies accidentally do, proved from outside my own account that it was genuinely reachable, then locked it down properly and added a scoped, temporary access token for legitimate use instead of leaving it permanently sealed.
